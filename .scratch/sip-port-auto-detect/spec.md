# 网关注册:SIP 端口自动探测与文案调整

## 背景

2026-08-29 诊断确认:teleflow 的 pjsua2 UDP transport 固定绑定 `sip_port`(默认 5060),而同一台机器上的 FreeSWITCH 也监听 `192.168.1.189:5060`。REGISTER 从 `.189:5060` 发往 `.189:5060`,FreeSWITCH 的 401/200 响应回给源地址后被 Windows 投递给"最特定地址"套接字(FreeSWITCH 自身),pjsua2 永远收不到 → `408 Request Timeout`。实测把 `sip_port` 改为 5062 后立即注册成功。

## 决定

- `sip_port` 语义从"固定本地绑定端口"改为"可选的首选端口,空 = 自动"。
- 自动 mode:从 5060 起逐个探测,选第一个空闲端口。
- 显式指定:启动时检测该端口是否被占用;被占用则提醒用户并自动漂移到下一个空闲端口。

## 范围

1. 默认 `sip_port` 为空 → 自动检测;5060 被占用时自动漂移到下一个可用端口。
2. 可强制指定端口(config.json);指定后检测占用,占用则提醒用户。
3. 文案:"SIP 注册" → "网关注册"。
4. 设置 UI 移除"网关 Port"输入项(端口不再需要用户在 UI 中配置,仅 config.json 可强制指定)。
