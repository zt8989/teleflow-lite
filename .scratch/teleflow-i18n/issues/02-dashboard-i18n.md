# 02: 仪表盘 DashboardWidget 国际化 + retranslate

**What to build:** 把主窗口仪表盘里所有用户可见的静态文本改为走 `tr()`，并支持运行时切换后无需重启即刷新。交付：

- `DashboardWidget` 的构造阶段文本（扬声器/播放、麦克风/采集标签、刷新设备、调试/生产模式按钮、测试汇报按钮、模式预设标签、通话状态/汇报状态分组标题与初始值、统计项标题等）全部改为 `tr("<key>")`。
- 实现 `DashboardWidget.retranslate(self)`：重新为上述静态控件赋值（同一组 key），供语言切换时调用。
- 动态/状态驱动文本（如通话状态「空闲」→「通话中」、SIP 运行/注册状态）渲染时也走 `tr()`，保证切换即时生效。
- 相关 key 写入 `en.json` 与 `zh_CN.json`（中文为权威源，提供英文译文）。

**Blocked by:** 01 (i18n 核心机制 + `tr`).

**Status:** ready-for-agent

- [ ] 仪表盘所有静态标签/按钮/状态初值均通过 `tr()` 取值，无残留中文裸字符串。
- [ ] `retranslate()` 覆盖全部静态文本；语言切换后不重启即可刷新。
- [ ] 状态类文本（通话/汇报状态、SIP 注册）切换语言后实时更新。
- [ ] 新增/补全的 key 在 `en.json` 与 `zh_CN.json` 中成对存在。
